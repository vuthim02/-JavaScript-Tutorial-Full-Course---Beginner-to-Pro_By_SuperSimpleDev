# 🎯 HOW TO STUDY THESE WEBSITES

## Analysis Framework

For each website, analyze:

```
┌─────────────────────────────────────────────────────────┐
│  1️⃣  FIRST IMPRESSIONS (0-5 seconds)                    │
│      • What do you notice first?                        │
│      • Is the purpose clear?                            │
│      • Does it feel trustworthy?                        │
├─────────────────────────────────────────────────────────┤
│  2️⃣  NAVIGATION & STRUCTURE                             │
│      • How many clicks to key content?                  │
│      • Is the menu intuitive?                           │
│      • Can you find your way back?                      │
├─────────────────────────────────────────────────────────┤
│  3️⃣  VISUAL DESIGN                                      │
│      • Color palette and consistency                    │
│      • Typography hierarchy                             │
│      • Whitespace usage                                 │
├─────────────────────────────────────────────────────────┤
│  4️⃣  CONTENT & COPY                                     │
│      • Is the value proposition clear?                  │
│      • Is the language user-friendly?                   │
│      • Are CTAs compelling?                             │
├─────────────────────────────────────────────────────────┤
│  5️⃣  INTERACTIONS & MICRO-INTERACTIONS                  │
│      • Hover states                                     │
│      • Animations and transitions                       │
│      • Loading states                                   │
├─────────────────────────────────────────────────────────┤
│  6️⃣  MOBILE EXPERIENCE                                  │
│      • Responsive design quality                        │
│      • Touch target sizes                               │
│      • Mobile-specific features                         │
└─────────────────────────────────────────────────────────┘
```

## Learning Exercises

### Exercise 1: Screenshot Analysis
1. Take screenshots of 5 websites
2. Identify 3 UI patterns you like
3. Identify 3 UX improvements you'd make
4. Sketch alternative layouts

### Exercise 2: Competitive Analysis
1. Pick one category (e.g., SaaS)
2. Compare 3 websites in that category
3. Create a feature comparison matrix
4. Note best practices from each

### Exercise 3: Redesign Challenge
1. Find a website with poor UX
2. Document the problems
3. Create wireframes for improvement
4. Build a high-fidelity mockup
