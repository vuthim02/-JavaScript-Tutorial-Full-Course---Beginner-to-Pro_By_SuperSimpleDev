# JavaScript Full Course - Beginner to Pro

A comprehensive JavaScript course based on the SuperSimpleDev tutorial. Learn JavaScript from scratch to advanced level with hands-on projects.

**Video Source:** [JavaScript Tutorial Full Course - Beginner to Pro](https://youtu.be/EerdGm-ehJQ)

## Course Overview

This course takes you from JavaScript beginner to professional through:
- 18 major sections covering all JavaScript fundamentals
- 22+ hours of video content
- Hands-on projects including Amazon-style e-commerce site
- Rock Paper Scissors game, To-Do List, Calculator

## Prerequisites

- No previous coding experience required
- A computer with internet access
- Code editor (VS Code recommended)
- Browser for testing (Chrome recommended)

## How to Use This Course

1. Navigate to the `modules/` directory
2. Start with Module 1: JavaScript Basics
3. Complete each lesson with its exercises
4. Build the projects as you progress
5. Complete the final Amazon project

## Projects Built

- **Cart Quantity Calculator** - Basic arithmetic operations
- **Rock Paper Scissors Game** - Game logic with user input
- **To-Do List** - DOM manipulation and array methods
- **Calculator** - Advanced functions and event handling
- **Amazon Clone** - Full e-commerce site with cart, orders, tracking

## Getting Started

```bash
# Clone the course repository
git clone https://github.com/SuperSimpleDev/javascript-course

# Or open any module file in your browser
open modules/01-javascript-basics/lesson-01.html
```
