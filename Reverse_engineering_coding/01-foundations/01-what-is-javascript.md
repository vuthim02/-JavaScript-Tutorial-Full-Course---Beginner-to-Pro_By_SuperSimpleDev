## Brendan Eich 

Imagine a website is like a house:

- **HTML** is the structure — the walls, floors, and rooms.
- **CSS** is the decoration — the paint, furniture, and curtains.
- **JavaScript** is the electricity and plumbing — it makes things *work*.

Without JavaScript, websites are just static documents — like a printed newspaper. You can read them, but you can't interact with them.

## JavaScript's Characteristics

| Characteristic | Plain English Meaning |
|---|---|
| **High-level** | You write human-readable code. JavaScript manages memory for you. |
| **Dynamically typed** | You don't have to tell JavaScript what *type* of data a variable holds. |
| **Multi-paradigm** | You can write JavaScript in many styles — procedural, object-based, or functional. |
| **Prototype-based** | Objects can inherit features from other objects. |
| **Event-driven** | JavaScript is designed to *respond* to things: clicks, timers, data arriving. |
| **Single-threaded** | JavaScript does one thing at a time on the same thread. |
| **Garbage-collected** | Unused data is automatically cleaned up from memory. |

## Where JavaScript Runs

| Environment | What It Is | Examples |
|---|---|---|
| **Browsers** | The original home of JavaScript | Chrome, Firefox, Safari, Edge |
| **Node.js** | Runs JS on servers, built on the V8 engine | Backend servers, CLI tools |
| **Bun** | A newer, faster runtime | Alternative to Node.js |
| **Deno** | A secure runtime by Node.js's creator | Supports TypeScript natively |
| **Electron** | Builds desktop apps with JS | VS Code, Slack, Discord |
| **React Native** | Builds mobile apps with JS | Cross-platform iOS + Android |
| **Embedded** | Tiny devices, IoT | Drones, smartwatches |

## Why Was JavaScript Created?

In 1995, every website was a static HTML page. If you submitted a form, the entire page had to reload. Brendan Eich was asked to create a scripting language for the Netscape browser. He built the first version in **10 days**. This is why JavaScript has some quirks.

| Question | Answer |
|---|---|
| What problem does JS solve? | Makes web pages interactive |
| Why is HTML alone insufficient? | HTML describes structure, not behavior |
| Why can't CSS do logic? | CSS cannot perform general-purpose logic like loops, conditionals, or functions (CSS Custom Properties are data-only, not logic) |
| What makes JS different from Java? | Completely different languages — similar name was a marketing decision |
| Why was it built in 10 days? | Explains its quirks and historical oddities |
| Why is it the most used language? | It runs everywhere — browsers, servers, mobile, desktop, IoT |
