# Exercises — Reverse Engineering JavaScript

Practice each concept right after studying it. Each exercise file corresponds to a module.

## How to Run

```bash
# Run all exercises for a module
node exercises/01-foundations.js

# Or from the module directory
node ../exercises/01-foundations.js
```

## Tips

- Try writing the solution yourself before running the test
- Use the RE 3-Level Q&A from the theory files when you get stuck
