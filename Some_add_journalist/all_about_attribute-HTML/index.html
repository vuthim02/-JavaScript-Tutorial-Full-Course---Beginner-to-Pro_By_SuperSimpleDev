HTML Attributes — The Complete Guide

An attribute is extra information you add inside an HTML opening tag. It always follows this pattern:

<tagname attribute="value">content</tagname>

1. Global Attributes (work on any element)

AttributeWhat it doesExample
idUnique identifier (only ONE per page)<div id="header">
classCSS class selector (can reuse)<button class="btn primary">
styleInline CSS<p style="color:red">
titleTooltip on hover<abbr title="World Health Org">WHO</abbr>
hiddenHides the element (boolean)<div hidden>secret</div>
tabindexTab order for keyboard nav<input tabindex="1">
langLanguage of the element<p lang="fr">Bonjour</p>
dirText direction (ltr / rtl)<p dir="rtl">سلام</p>
contenteditableLet user edit the text<div contenteditable>edit me</div>
draggableAllow drag-and-drop<img draggable="false">
spellcheckEnable/disable spell check<textarea spellcheck="true">
data-*Custom data (any name after "data-")<button data-user-id="42">
Tip: id must be unique. Never use the same id twice on a page. Use class for repeated styling.

2. The data-* Attribute (deep dive)

data- is special because you invent the rest of the name yourself:

<button
  data-choice="rock"
  data-player="1"
  data-score="10"
>Rock</button>

How JavaScript reads it:

// HTML  →  JS (dataset)
data-choice  →  element.dataset.choice     // "rock"
data-player  →  element.dataset.player     // "1"
data-score   →  element.dataset.score      // "10"

// Hyphens become camelCase:
data-user-id  →  element.dataset.userId
data-game-mode → element.dataset.gameMode
CSS can read it too:
button[data-choice="rock"] { background: gray; }
button::after { content: attr(data-score); }

Why use data-* instead of id/class?

  • id is unique — can't have 3 buttons with id="rock"
  • class is for styling/selectors, not storing values
  • data-* keeps data right on the element — no separate lookup needed

Boolean attributes work two ways:
✅ <input disabled> (HTML5 style)
✅ <input disabled=""> or <input disabled="disabled">
❌ <input disabled="false"> — this does NOT enable it! The attribute just being present = true.

5. Event Handler Attributes (old way)

You CAN put JavaScript directly in HTML, but modern code uses addEventListener instead:

<button onclick="alert('clicked')">Click</button>
AttributeFires when...
onclickElement is clicked
ondblclickDouble-clicked
onmouseoverMouse enters the element
onmouseoutMouse leaves the element
onchangeInput value changes (after blur)
oninputInput value changes (every keystroke)
onsubmitForm is submitted
onkeydownKey is pressed
onloadPage / image finishes loading
Modern best practice: Keep HTML clean, add events in JS:
document.querySelector('button').addEventListener('click', () => {...});

9. Putting It All Together — Real Example

<form action="/signup" method="POST">
  <label for="email">Email</label>
  <input
    id="email"
    name="email"
    type="email"
    placeholder="you@example.com"
    required
    autocomplete="email"
  >

  <button
    type="submit"
    class="btn btn-primary"
    data-loading="false"
    aria-label="Sign up for newsletter"
  >
    Sign Up
  </button>
</form>

10. Summary

  • Global: id, class, style, title, hidden, lang, dir, data-*
  • Form: type, name, value, placeholder, required, disabled, checked, min, max, step
  • Link/Media: href, src, alt, width, height, target, rel, controls, autoplay, loop
  • Boolean: Just being present = true, absent = false
  • data-*: Custom attributes — JS reads via element.dataset.name
  • ARIA: role, aria-label, aria-hidden, aria-expanded (for accessibility)
  • Events: onclick, onchange, etc. — but use addEventListener in JS instead
