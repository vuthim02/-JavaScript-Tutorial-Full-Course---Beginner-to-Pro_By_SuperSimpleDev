Quick Overview

What is Linux?

Linux is a family of open-source operating systems based on a kernel first released publicly on September 17, 1991 by Linus Torvalds.

Learn more →

Who is Linus Torvalds?

A Finnish-American software engineer who created the Linux kernel and Git, the version control system used by developers worldwide.

Learn more →

Why Open Source?

Linux introduced the world to the power of collaboration: thousands of developers around the globe building software together, freely and openly.

Learn more →

Did You Know?

Linux runs about 90% of the public cloud workload and powers the vast majority of the world's supercomputers, yet it all started as a hobby project written by one student.

A Word From the Creator Quote

"Talk is cheap. Show me the code." — Linus Torvalds, 2000
Read more about this famous quote

Linus wrote this in a mailing list discussion in August 2000, responding to someone who questioned the power of Linux. It captures the open-source spirit: action and working code matter more than words.

Where is BDFL used?

"BDFL" describes a single leader who has final say over a project. Linus Torvalds famously holds this title for the Linux kernel, and also held it for the Git project.
