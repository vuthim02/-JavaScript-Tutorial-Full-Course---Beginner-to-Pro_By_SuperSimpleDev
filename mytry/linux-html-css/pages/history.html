History of Linux

From a student's hobby to the backbone of the modern internet.

A Timeline of Linux

1969

Ken Thompson and Dennis Ritchie at AT&T's Bell Labs develop the UNIX operating system, which becomes the intellectual ancestor of Linux. Its design philosophy shapes operating systems for decades.

1983

Richard Stallman launches the GNU Project with the goal of creating a completely free UNIX-like operating system. GNU tools and the GPL license later become essential to Linux.

1991

A 21-year-old computer science student named Linus Torvalds announces his hobby operating system on the Usenet newsgroup comp.os.minix. On August 25, he writes the now-famous message asking for feedback. The name "Linux" is coined.

September 17, 1991

Linux version 0.01 is released publicly on the FTP server of Helsinki University of Technology. While tiny (about 10,000 lines of code), it already captures the imagination of programmers worldwide.

1992

Linux is re-licensed under the GNU General Public License (GPL), aligning it with the free software movement and paving the way for massive community collaboration.

1994

Linux kernel 1.0 is released in March, marking the first official stable version. It includes about 176,000 lines of code and supports only Intel 386 processors.

1996

The Linux mascot, "Tux" the penguin, is officially chosen as the Linux logo. Linus had been bitten by a penguin during a visit to Australia, inspiring the choice.

1998-2000

Major companies like IBM, Oracle, and Intel begin investing in Linux. The open-source movement gains momentum with the 1998 release of the Netscape browser source code and the founding of the Open Source Initiative.

2003

The Linux kernel moves to version 2.6, bringing improvements in scalability that help it handle larger systems and become a serious server platform.

2008

Google's Android operating system, built on the Linux kernel, is introduced. It quickly becomes the most widely used mobile operating system in the world.

2011

Linux celebrates its 20th birthday. The kernel now contains over 14 million lines of code contributed by thousands of developers worldwide.

2015

Linux kernel version 4.0 is released on the 20th anniversary of version 1.0. It introduces live kernel patching, allowing updates without rebooting.

Today

Linux powers the majority of public cloud workloads, the world's top 500 supercomputers, billions of Android devices, routers, smart TVs, and much of the modern internet infrastructure.

The Famous Announcement Code

On August 25, 1991, Linus posted this legendary message to the comp.os.minix newsgroup: 

Hello everybody out there using minix -

I'm doing a (free) operating system (just a hobby, won't be big and
professional like gnu) for 386(486) AT clones.  This has been brewing
since april, and is starting to get ready.  I'd like any feedback on
things people like/dislike in minix...

          Linus

You can Ctrl + F your way through the web to find it, but the message lives forever in the history of computing.
