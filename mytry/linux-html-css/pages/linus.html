Linus Torvalds

The software engineer who started a revolution with a hobby project.

Who is Linus Torvalds?

Linus Benedict Torvalds is a Finnish-American software engineer, born on December 28, 1969, in Helsinki, Finland. He is best known as the creator and principal developer of the Linux kernel and the creator of Git, the version control system used by software teams around the world.

What began in 1991 as a personal project — a "just a hobby, won't be big and professional" operating system — grew into the most successful open-source software in history.

Key Facts

  • Born: December 28, 1969, in Helsinki, Finland
  • Education: University of Helsinki (Computer Science)
  • Creator of: The Linux kernel (1991) and Git (2005)
  • Nationality: Finnish and American citizen
  • Leadership: Benevolent Dictator for Life (BDFL) of the Linux kernel project
  • Awards: Millennium Technology Prize (2012), IEEE Computer Pioneer Award, among many others
  • Famous quote: "Talk is cheap. Show me the code." (1991, when challenged about the power of Linux)

The Linux Mascot: Tux

The Linux mascot is a penguin named Tux, chosen in 1996. The idea came about because Linus Torvalds was once bitten by a penguin at a zoo in Australia. The name "Tux" stands for (T)orvalds (U)ni(X), and the mascot was designed by Larry Ewing.

Git: Another Gift

In 2005, Linus developed Git, a distributed version control system, to manage the rapidly growing Linux kernel development. It is now the standard tool for version control used by platforms like GitHub and GitLab.

Try Git Commands Code

Some everyday Git commands you can try on your own terminal: 

git init
git add index.html
git commit -m "First commit"
git push origin main

Press Ctrl + C to stop a running command, and Ctrl + L to clear your terminal.
