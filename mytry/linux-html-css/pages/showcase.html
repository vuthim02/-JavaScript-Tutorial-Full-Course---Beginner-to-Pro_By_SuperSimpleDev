Multi-column text

Linux began as a hobby in 1991 and today powers most of the modern internet. Its development is driven by thousands of contributors cooperating through a mailing list and, since 2005, the Git version control system created by Linus Torvalds himself. The kernel itself is a relatively small piece of the puzzle: any Linux distribution combines it with a bootloader, GNU tools, a desktop environment, and applications. Together these form an operating system that is free, open, and endlessly customizable.
