# Project: Rock Paper Scissors

A classic game built with vanilla JavaScript.

## Files

- `index.html` - Game interface
- `script.js` - Game logic

## How to Play

1. Open `index.html` in a browser
2. Click Rock, Paper, or Scissors button
3. See the result and updated score

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice = Draw

## Features

- Score tracking
- Move history
- Random computer choice
- Visual feedback
