# PHP Authentication System

Full-stack authentication system with PHP backend featuring user registration, login, and a protected dashboard.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- PHP (backend)
- MySQL (database)

## How to Run

1. Start a PHP-enabled server (e.g., XAMPP, MAMP, or `php -S localhost:8000`)
2. Configure the database connection in the PHP files
3. Navigate to `http://localhost:8000`

## Features

- User registration with form validation
- Secure login/logout with session management
- Protected dashboard page
- Password hashing for security
