# Full API Architecture

Full-stack application demonstrating client/server separation with an Express proxy server and SQLite database.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Node.js / Express (proxy server)
- SQLite (database)

## How to Run

1. Run `npm install`
2. Run `npm start`
3. Navigate to `http://localhost:3000`

## Features

- Client/server architecture separation
- Express proxy API layer
- SQLite database for persistence
- RESTful API design
