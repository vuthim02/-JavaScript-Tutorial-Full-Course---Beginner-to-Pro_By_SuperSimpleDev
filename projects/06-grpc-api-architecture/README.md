# gRPC API Architecture

gRPC-based API project demonstrating Protocol Buffers, proxy layers, and authentication patterns.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- gRPC / Protocol Buffers (Protobuf)
- Node.js
- Proxy server

## How to Run

1. Run `npm install`
2. Compile protobuf definitions if needed
3. Run `npm start`

## Features

- gRPC service definitions with Protobuf
- Proxy API layer
- Authentication integration
- Bidirectional streaming support
