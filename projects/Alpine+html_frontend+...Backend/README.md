# Alpine.js Frontend + Express Backend

Full-stack application with an Alpine.js reactive frontend and Express.js backend API.

## Tech Stack

- HTML5, CSS3
- Alpine.js (frontend reactivity)
- Node.js / Express (backend API)

## How to Run

1. Run `npm install` in the backend directory
2. Run `npm start` to start the Express server
3. Navigate to `http://localhost:3000`

## Features

- Reactive UI with Alpine.js
- RESTful Express API backend
- Frontend/backend separation
- Lightweight alternative to heavy frameworks
