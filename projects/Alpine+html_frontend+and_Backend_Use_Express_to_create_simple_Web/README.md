# Alpine.js + Express Backend

Simple full-stack web application with Alpine.js frontend and Express.js backend.

## Tech Stack

- HTML5, CSS3
- Alpine.js (frontend reactivity)
- Express.js (backend API)

## How to Run

```bash
npm install
node server.js
```

Then open `http://localhost:3000` in your browser.

## Features

- Lightweight frontend with Alpine.js
- RESTful API with Express.js
- Server-side rendering
- Clean project structure with public/ directory
