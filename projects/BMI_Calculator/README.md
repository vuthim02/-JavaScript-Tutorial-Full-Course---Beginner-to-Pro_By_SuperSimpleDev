# BMI Calculator

Body Mass Index calculator that computes BMI from height and weight inputs and displays the health category.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## How to Run

1. Open `index.html` in a browser

## Features

- Metric and imperial unit support
- Instant BMI calculation
- Health category display (underweight, normal, overweight, obese)
- Input validation
