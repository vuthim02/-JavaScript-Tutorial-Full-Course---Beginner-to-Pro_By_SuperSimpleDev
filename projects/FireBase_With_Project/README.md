# Firebase Projects

Collection of Firebase hosting projects including an e-commerce store (Google Store) and additional demos.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Firebase Hosting
- Firebase Firestore / Realtime Database

## How to Run

1. Install Firebase CLI: `npm install -g firebase-tools`
2. Run `firebase login`
3. Navigate to the desired sub-project (A2, A3, hosted-app, google-store)
4. Run `firebase serve` for local development

## Features

- Firebase hosting deployment
- Real-time database integration
- Google Store e-commerce demo (google-store)
- Multiple project configurations
