# GraphQL Projects

Collection of GraphQL projects ranging from beginner to intermediate, demonstrating queries, mutations, and full-stack implementations.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- GraphQL
- Node.js / Express

## How to Run

1. Navigate to the desired project sub-folder
2. Run `npm install`
3. Run `npm start`
4. Open the GraphQL playground or frontend

## Features

- Beginner GraphQL queries and mutations
- Intermediate schema design
- Full-stack GraphQL applications
- Schema stitching and resolvers
