# JavaScript as Backend

Node.js backend application with JWT authentication. This project demonstrates server-side JavaScript with secure token-based auth.

## Tech Stack

- Node.js / Express
- JSON Web Tokens (JWT)
- (See sub-folder READMEs for additional details)

## How to Run

1. Run `npm install`
2. Run `npm start`
3. Navigate to `http://localhost:3000`

## Features

- JWT-based authentication
- Protected route middleware
- Express API routing
- Server-side JavaScript patterns
