# JavaScript Type Detective

Interactive playground for exploring and detecting JavaScript data types at runtime.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## How to Run

1. Open `index.html` in a browser

## Features

- Detect any value's data type
- Compare `typeof` vs `instanceof` behavior
- Explore edge cases (null, arrays, objects)
- Interactive input for live type checking
