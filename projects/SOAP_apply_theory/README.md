# SOAP API Projects

Collection of SOAP API projects from beginner to full implementation, demonstrating XML-based web services.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- SOAP / XML Web Services
- Node.js

## How to Run

1. Navigate to the desired sub-folder (beginner or full)
2. Run `npm install`
3. Run `npm start`

## Features

- SOAP request/response handling
- XML parsing and generation
- SOAP client implementation
- Beginner and full project levels
