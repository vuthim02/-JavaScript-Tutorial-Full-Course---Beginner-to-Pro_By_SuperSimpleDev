SOAP Message Structure

Every SOAP message is an XML document with a fixed structure:

<soap:Envelope>
<soap:Header> (optional)
Security tokens
Routing info
Transaction IDs
</soap:Header>
<soap:Body>
Request / Response payload
<soap:Fault> (on error)
Error code & details
</soap:Fault>
</soap:Body>
</soap:Envelope>

Envelope

Root element — wraps the entire message. Declares XML namespaces.

Header

Optional — carries metadata like authentication tokens, routing, transaction IDs.

Body

Required — contains the actual request (method call) or response data.

Fault

Optional error container inside Body. Includes fault codes, strings, and details.
