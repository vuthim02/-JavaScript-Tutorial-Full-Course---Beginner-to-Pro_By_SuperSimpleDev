WS-Security Lab

SOAP messages with UsernameToken authentication

Username Token

The UsernameToken is placed in the SOAP Header to authenticate the client. 

// UsernameToken XML will appear here

How It Works

  1. Client builds UsernameToken in the SOAP Header
  2. Server validates the token before processing the Body
  3. If invalid, a SOAP Fault is returned

Try wrong credentials to see the SOAP Fault response.
