HTML (HyperText Markup Language) is the standard language for creating web pages. It structures content using elements like headings, paragraphs, links, and images.

CSS (Cascading Style Sheets) controls the visual presentation of HTML elements. It handles colors, layouts, fonts, and responsive design.

JavaScript is a programming language that adds interactivity to web pages. It can manipulate the DOM, handle events, and communicate with servers.
