# Telegram Bot

Telegram bot with RSS feed integration, AI-powered summarization, and a monitoring dashboard.

## Tech Stack

- Node.js
- Telegram Bot API
- RSS parsing library
- AI summarization API

## How to Run

1. Copy `.env.example` to `.env` and fill in your API keys
2. Run `npm install`
3. Run `npm start`
4. Open the dashboard at the configured port

## Features

- RSS feed subscription and monitoring
- AI-powered content summarization
- Web-based monitoring dashboard
- Configurable via environment variables
