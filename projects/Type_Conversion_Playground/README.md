# Type Conversion Playground

Interactive single-page playground for exploring JavaScript type conversion and coercion rules.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## How to Run

1. Open `index.html` in a browser

## Features

- Explore explicit type conversions (Number, String, Boolean)
- See implicit coercion in action
- Side-by-side comparison of conversion results
- Single-file application
