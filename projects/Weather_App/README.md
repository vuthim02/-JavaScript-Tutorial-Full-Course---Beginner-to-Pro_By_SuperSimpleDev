# Weather App

Weather application that fetches and displays current weather data for any location.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Weather API (OpenWeatherMap or similar)

## How to Run

1. Open `index.html` in a browser
2. Ensure a valid API key is configured in the source

## Features

- Search by city name
- Current temperature and conditions display
- Humidity, wind speed, and icon representation
- Responsive weather dashboard
