# Vue.js + Express + MongoDB Full-Stack App

Full-stack application using Vue.js frontend, Express.js backend, MongoDB database, and Docker containerization. Includes a News App sub-project.

## Tech Stack

- Vue.js (frontend)
- Node.js / Express (backend API)
- MongoDB (database)
- Docker / Docker Compose

## How to Run

1. Install Docker and Docker Compose
2. Run `docker-compose up`
3. Navigate to `http://localhost:8080`

## Features

- Vue.js reactive frontend
- RESTful Express API
- MongoDB data persistence
- Docker containerized deployment
- News App sub-project included
