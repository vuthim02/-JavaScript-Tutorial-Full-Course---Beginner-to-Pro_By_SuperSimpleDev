# Vue.js + Express + MongoDB Full-Stack App

Full-stack application with Vue.js frontend, Express.js backend, and MongoDB database. Includes Docker Compose for containerized deployment. Also contains a News_App sub-project.

## Tech Stack

- Vue.js 3 (frontend)
- Express.js (backend API)
- MongoDB / Mongoose (database)
- Docker Compose (deployment)

## How to Run

```bash
# With Docker
docker-compose up

# Without Docker
cd server && npm install && npm start
cd client && npm install && npm run serve
```

## Features

- Vue.js 3 with component-based architecture
- RESTful API with Express.js
- MongoDB with Mongoose ODM
- Docker Compose for easy deployment
- News_App sub-project included
