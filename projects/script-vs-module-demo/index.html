📊 Summary Comparison

🔴 Traditional Script

  • Global scope pollution
  • No import/export
  • Executes immediately
  • No top-level await
  • Strict mode opt-in
  • Loads multiple times
  • No CORS restrictions

🟢 Module Script

  • Private module scope
  • Full import/export
  • Deferred execution
  • Top-level await
  • Always strict mode
  • Loaded once (cached)
  • CORS required
